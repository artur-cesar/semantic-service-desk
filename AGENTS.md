# Monorepo conventions

This repository contains separate backend and frontend applications.

- Work on the Node.js API under `backend/` and follow `backend/AGENTS.md`.
- Work on the React user interface under `frontend/` and follow
  `frontend/AGENTS.md`.
- Keep repository-wide automation under the repository root.
- Run backend npm commands from `backend/` or with `npm --prefix backend`.
- Run frontend npm commands from `frontend/` or with `npm --prefix frontend`.
- English is the official language for source code, documentation, logs,
  tests, and commit messages.
